# DB-SQL-NoSQL-Master-degree
Repository for master degree course: "SQL and NoSQL databases"

- Первичные ключи, внешние ключи, constraints (на поля и внешние ключи)
- DML, DDL, DCL, TCL
- Реляционная алгебра (замкнутость, операции алгебры)
- Нормальные формы (1НФ, 2НФ, 3НФ, НФБК)
- Транзакции. ACID. Аномалии. Блокировки
- Конфликты RR/RW/WR/WW
- Уровни изоляции
- 2-х фазный коммит

**Операции SQL**
- SELECT (полный, со столбцами, с фильтрацией)
- INSERT/UPDATE/DELETE
- CREATE
- Агрегирующие функции (min, max, avg, count ...)
- GROUP BY, HAVING
- Псевдонимы
- JOINS
- DISTINCT, LIMIT, ORDER
